# [3] C. S. Horstmann (2024) - Core Java, Volume I: Fundamentals (13th Edition)

Tài liệu kỹ thuật chuyên sâu do Pearson xuất bản năm 2024 (ISBN-13: 978-0-13-532837-8) trình bày nền tảng lập trình đa luồng (ThreadPoolExecutor, ConcurrentHashMap), quản lý tài nguyên an toàn (try-with-resources), giao tiếp JDBC (PreparedStatement) và xử lý mật mã bằng API chuẩn Java.

Trang tác giả chính thức của ấn phẩm được xác thực tại: https://horstmann.com/corejava/ (Truy cập ngày 18/11/2026).

Tài liệu này dự kiến trích dẫn trong báo cáo tại Mở đầu (Mục 3), Chương 2 (Mục 2.2.1, Mục 2.2.3, Mục 2.2.4) và Chương 3 (Mục 3.3.1).
