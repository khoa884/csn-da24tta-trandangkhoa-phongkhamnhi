# [7] Oracle Corporation (2025) - MySQL 8.0 Reference Manual: InnoDB Locking & Transaction Model

Tài liệu kỹ thuật chính thức về cơ chế giao dịch ACID của bộ máy lưu trữ InnoDB, khóa dòng độc quyền (Exclusive Row Lock) với câu lệnh SELECT ... FOR UPDATE, khóa khoảng cách (Gap Lock) và nguyên tắc giữ thứ tự khóa cố định để ngăn chặn Deadlock.

Tài liệu trực tuyến của MySQL Reference Manual được xác thực tại: https://dev.mysql.com/doc/refman/8.0/en/innodb-locking-transaction-model.html (Truy cập ngày 18/11/2026).

Tài liệu này dự kiến trích dẫn trong báo cáo tại Mở đầu (Mục 3), Chương 2 (Mục 2.2.2) và Chương 3 (Mục 3.1.3, Mục 3.2.2, Mục 3.3.2).
