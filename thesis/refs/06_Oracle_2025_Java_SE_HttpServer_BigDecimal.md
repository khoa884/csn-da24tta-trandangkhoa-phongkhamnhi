# [6] Oracle Corporation (2025) - Java SE 25 Platform API Specification (jdk.httpserver & BigDecimal)

Tài liệu đặc tả chính thức của Oracle cho Java SE 25 đối với gói máy chủ HTTP nhúng com.sun.net.httpserver.HttpServer, đối tượng HttpExchange, phân tích ngày giờ java.time.LocalDate.parse / LocalTime.parse và số học thập phân chính xác java.math.BigDecimal với RoundingMode.HALF_UP.

Tài liệu trực tuyến của Oracle Help Center được xác thực tại: https://docs.oracle.com/en/java/javase/25/docs/api/jdk.httpserver/com/sun/net/httpserver/package-summary.html (Truy cập ngày 18/11/2026).

Tài liệu này dự kiến trích dẫn trong báo cáo tại Mở đầu (Mục 3), Chương 2 (Mục 2.2.1, Mục 2.2.2) và Chương 3 (Mục 3.1.1).
